04 / Attack surfaces

Attack surfaces

LLM01 / Prompt injection

Untrusted instructions

Attack

Malicious text in a web page, PDF or retrieved document redirects an agent.

Validate

Tool-call denial, origin separation, and benign-task completion.

Agent permissions

Excessive agency

Attack

An assistant with broad connector scopes reads or modifies resources outside the task.

Validate

Per-user and per-resource authorization; high-risk action approval.

RAG / Memory

Poisoned context

Attack

Manipulated retrieved results or persistent memory bias downstream decisions.

Validate

Provenance, access-scoped retrieval, poisoning tests and corpus review.

Data / Egress

Information exfiltration

Attack

Agent outputs or tool calls expose secrets to unauthorized destinations.

Validate

Destination allowlists, DLP checks, canary tests and network telemetry.

Runtime / Execution

Unsafe code execution

Attack

Untrusted repository instructions trigger shell commands or privileged container access.

Validate

Non-root runtime, restricted mounts, seccomp and blocked host credentials.

Supply chain

Compromised dependencies

Attack

Malicious package, model artifact or CI dependency enters an AI application.

Validate

Provenance, scanning, pinned dependencies and release policy gates.
