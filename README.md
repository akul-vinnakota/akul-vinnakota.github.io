# AI Security Research — GitHub Pages

A minimal static one-page personal research profile. No JavaScript, external fonts, animations, analytics, or dependencies.

## Publish

1. Back up the current GitHub Pages repository before making changes.
2. Replace the root `index.html` in the `akul-vinnakota.github.io` repository with this `index.html`, and upload `portrait.jpg` to the same directory.
3. Commit and push; GitHub Pages will serve the new homepage if Pages is configured for that branch.
4. Add links to specific upstream pull requests or security reports only after they exist, and revise the open-source text accordingly.
5. For Google indexing, verify the site in Google Search Console and request indexing of the homepage.
